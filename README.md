# Noctea

Home과 Characters만 남긴 Jekyll 기반 개인 캐릭터 아카이브입니다.

## 수정 위치

- 홈 데이터: `_data/home.yml`
- 홈 편집기: `tools/home-editor.html`
- 캐릭터 데이터: `_characters/*.md`
- 캐릭터 편집기: `tools/character-manager.html`
- 캐릭터 이미지: `assets/characters/`

GitHub Pages 프로젝트 저장소 이름을 바꾸면 `_config.yml`의 `baseurl`과 에디터 안의 `/noctea-characters/` 경로도 새 이름에 맞게 변경하세요.
