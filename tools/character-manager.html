Character Manager

Basic workflow
  1. Character file에 이름, 이미지, 색상을 입력합니다.
  2. Add content에서 항목을 골라 내용을 추가합니다.
  3. Current items에서 Edit, 위/아래 이동, 삭제로 정리합니다.
  4. Preview를 확인하고 Save draft로 브라우저에 임시 저장합니다.
  5. Copy 또는 Download한 Markdown을 repo의 _characters 폴더에 넣습니다.

Character file

Add content

The first four facts appear on the Characters card. All facts appear below the portrait on the detail page.

Use any section name: NAME, PROFILE, KEYWORD, RELATIONSHIP, etc. The manager groups items with the same section name together.

Images are arranged in a tidy grid under the text. Keep one image path per line.

AU details format: section|TITLE, toggle|TITLE|open, text|TEXT, image|PATH. Use --- to start another toggle block.
