Commission Post Editor

목록 카드와 클릭 후 열리는 전체 공지를 한 개의 Markdown 파일로 만듭니다.

작성 방법
  • 커미션 타입 하나당 _commissions/파일명.md 한 개를 만듭니다.
  • 이미 등록된 글은 기존 .md 불러오기로 내용을 되채워 수정할 수 있습니다.
  • 이미지를 첨부하기 전에 게시글의 파일명을 먼저 정해주세요.
  • 대표 이미지는 목록 카드와 상세 페이지 상단에 함께 사용됩니다. 본문 이미지는 파일 선택이나 드래그앤드롭으로 추가할 수 있습니다.
  • 첨부 후 이미지를 repo에 저장을 누르고 noctea-characters 폴더를 선택하면 assets/commission/파일명/이 자동으로 만들어집니다.
  • 제목, 인용문, 목록, 링크, 이미지 버튼으로 긴 공지를 구성할 수 있습니다.
  • 접수된 슬롯은 ✿, 빈 슬롯은 ❀로 표시되며 예약 슬롯은 별도 숫자로 표시됩니다.
